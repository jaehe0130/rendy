# 렌디 웹 프로토타입 (디자인 참고용)

디자인 담당이 화면 흐름 · 문구 · 정책을 검증하려고 만든 **클릭 가능한 프로토타입**입니다.
실제 서비스 코드는 `apps/web`(Next.js)이고, 이 폴더는 **참고용**이라 워크스페이스(`pnpm-workspace.yaml`)에 들어가지 않습니다.

- 기술: Vite + React + TypeScript, 데이터는 브라우저(localStorage)에만 저장 · 서버/API 키 없음
- AI(추천 · 흠집 표시)는 예시 로직이라 화면에 "프로토타입" 표시가 있음
- 기능 정의 · 정책 숫자: [`design/spec/기능명세서.md`](../spec/기능명세서.md) (v3.2)
- Figma: https://www.figma.com/design/U6Ru7QuofrLJBg7wSBaFSy (와이어프레임 · 디자인 Rendy v5 · 기능명세서 페이지)

## 실행

```bash
cd design/prototype
npm install
npm run dev   # http://localhost:5173
```

## 시연 주소

| 주소 | 화면 |
|---|---|
| `/?demo` | 데모 회원(로그인 · 학교 인증 · 장바구니 채워짐)으로 시작 |
| `/products`, `/products/:id` | 상품 목록 · 상세(보장 3단계, 총비용) |
| `/ai?view=result` | AI 살림 상담 추천 결과 |
| `/quiz?view=result` | 1분 진단 결과 |
| `/my?demo&open=receive\|extend\|return` | 받은 날 확인 · 연장 · 반납 예비 판정 |
| `/sell?demo&view=quote` | 팔기(바이백) 예상 매입가 |
| `/login`, `/login?step=2&returning` | 로그인 · 회원가입 / 다시 온 회원 |
| `/admin?demo` | 운영 대시보드 |
| `/admin/judge?demo` | **반납 최종 판정 (AI 보조, 운영자 확정)** |
| `/admin` → 데모 초기화 | 브라우저 저장 데이터 초기화 |

## 11/5~11/6 팀 결정 반영 내용

1. **위탁(맡기기) 삭제 → 중고 매입(바이백)만** — 위탁 전용 품목(스탠바이미 · 청소기)도 삭제
2. **팔기에 AI 견적 없음** — 판매자 사진은 조명 · 각도가 제각각이라 AI 판정을 믿기 어렵고, 금액 기준은 설명 가능해야 함.
   예상 매입가 = 공식몰가 × 30%(구매 2년 이내) × 상태(판매자 선택), 범위로 보여주고 최종가는 수거 후 운영자 검수로 확정. 사진은 운영자 확인용
3. **로그인 · 회원가입 한 화면** — 휴대폰 인증, 가입한 번호면 약관 없이 바로 로그인 (해커톤 시연에서는 생략 가능)
4. **반납 판정은 운영자가 확정** — AI는 흠집 후보 · 길이만 표시. 2cm 기준 ±0.5cm는 "운영자 확인" 표시, 신뢰도 낮은 건부터 보여줌. AI 성능은 실험값(F1 0.73 · 길이 오차 평균 1.5cm · 자동 판정 정확도 57%) 그대로 표기

> 프로토타입 코드와 기능명세서에는 아직 렌디 이용자 매입 우대(+5%p)와 구매 1~2년 25% 구분이 남아 있음. 최종 BM(바이백 수정본)에는 없어서 Figma 디자인에서는 뺐음.
