# 서비스 개요

- **대상**: 성북구 1인 가구 (대학가에서 시작 — 성신여대·고려대·국민대·한성대·동덕여대·서경대·KC대)
- **핵심**: 생활가전 렌탈 구독. 2개월부터, 1개월 단위 연장. 세척·소모품 포함. 주 2회 지정일 배송 또는 동네 거점 수령.
- **요금**: 일반형(새 제품·A급 중고) / 실속형(B급·출시 3년 넘음, 월 5,000원 저렴)
- **파손 보장 단계 (렌터카 자차처럼)**: 기본 월 0원 · 안심 월 1,000원(자기부담 최대 1만 원) · 완전 안심 월 2,000원(렌탈당 1회 0원)
- **공급**: 떠나는 사람 가전을 바이백으로 매입 → 검수·세척 → 다시 렌탈

## AI가 하는 일
| 기능 | 화면 | 방식 | 사람 확인 |
|---|---|---|---|
| 흠집 찾기·길이 재기 (출고/받은 날/반납 비교) | 8-1~8-5 | 비전 (`ai/vision`) | 운영자 최종 판정 |
| AI 살림 상담 · 꾸러미 추천 | 3-1~3-2, 0-3 | LLM | - |
| 리뷰 요약 · 비교표 · 가이드 글 초안 | 0-1, 2-3, 6-5 | LLM | 운영자 검수 후 발행 |
| 상품 등록 초안 | 6-2 | LLM + 비전 | 담당자 확인 |
| 매입 견적 | 5-A1 | 비전 품목 인식 + 규칙 | 검수 후 확정 |
