# AI 흠집 탐지 실험 결과

> 발표 자료의 숫자는 이 문서에서만 가져온다. 바뀌면 여기 먼저 고친다.

## 1. 합성 데이터 테스트
- 데이터: 가전 사진에 흠집을 합성한 이미지 **150장** (정상 사진 40장 포함)

| 항목 | 결과 | 의미 |
|---|---|---|
| 흠집 있음/없음 구분 | AUROC **0.98** | 1에 가까울수록 잘 구분 |
| 흠집 위치 찾기 | AUROC **0.99** | |
| 정상 사진을 흠집으로 오탐 | **0 / 40장** | |
| 흠집 길이 측정 | 평균 약 **1.5cm** 오차 | |
| 2cm 기준 자동 판정 정확도 | **57%** | 길이 오차 때문에 기준 근처에서 흔들림 |

## 2. 실제 사진 테스트
- 데이터: 온라인에 올라온 중고 가전 사진 **3장** (규모가 작아 경향만 확인)
- 뚜렷한 흠집은 찾았지만 옅은 긁힘은 놓침
- 물건 테두리·반사광을 흠집으로 잘못 잡음
- 원인: 비교할 "흠집 없는 같은 물건 사진"(기준 사진)이 없었음

## 3. 서비스 설계에 반영한 결론
1. **출고 때 기준 사진을 같은 각도로 찍는다** (8-1 가이드 프레임, 6면) → 실사진 오탐의 원인 제거
2. **반납 사진과 기준 사진을 같은 면끼리 비교**해서 *새로 생긴* 흠집만 표시
3. **길이는 참고값, 최종 판정은 운영자** → 2cm 기준 ± `reviewMarginMm` 안이면 자동으로 "운영자 확인 필요"
4. 운영자가 고친 판정은 사유와 함께 저장 → **재학습 데이터**

## 4. 개선 아이디어 (발표에서 '다음 단계'로)
- 촬영 시 크기 기준 마커(스티커) 함께 찍기 → 길이 오차 감소
- 반사광 경고(8-1에 이미 '다시 찍기 안내' 있음)
- 운영 데이터로 오탐 패턴(테두리·반사) 재학습
