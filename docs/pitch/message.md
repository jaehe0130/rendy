# 발표 메시지 — AI 파손 판정

## 한 줄
> **"AI가 흠집을 찾고 길이를 재서 판정을 돕고, 최종 판정은 운영자가 합니다. 운영 데이터로 AI는 계속 좋아집니다."**

## 하지 않을 말
- "AI가 파손을 자동으로 판정합니다" ← 2cm 기준 자동 판정 정확도 57%라 근거가 약함

## 숫자 쓰는 법
- 강점: 흠집 유무 AUROC 0.98 · 위치 AUROC 0.99 · 정상 오탐 0/40 (합성 150장 기준이라고 함께 말하기)
- 한계를 먼저 말하고 설계로 답하기: "실제 사진에서는 반사광을 흠집으로 착각했다 → 그래서 출고 때 같은 각도의 기준 사진을 찍게 설계했다"
- 8-5 화면의 'AI 성능' 수치는 실험값 또는 '목표'로 표기 (open-issues 참고)

## 데모 순서 (3분)
1. 8-1 운영자 출고 촬영 → AI가 기존 흠집 2곳 기록
2. 8-3 고객 반납 → 새 흠집 1곳만 표시, 1.6cm 생활 마모 → 0원 (기준 근처라 "운영자 확인" 배지)
3. 8-4 과실 파손 케이스 → 보장 단계별 부담 비교
4. 8-5 운영자가 확정/수정 → "수정 사유가 재학습 데이터로"
